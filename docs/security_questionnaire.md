# 보안 질의서 답변서

작성: 7주차 실습 담당자 | 기준일: 2026-10-13 | 검토 요청: 정보보호·준법 담당자

## 1. 데이터 흐름

```text
사용자 질문 → API Key 인증·호출 제한 → PII 마스킹
          → 로컬 임베딩·Qdrant/BM25·리랭킹
          → 외부 LLM API(실습 모드 1) / 내부 GPU(폐쇄망 모드 2)
          → 답변 + 근거·기준일·고지·정책 버전
          → 감사 로그(JSONL: 질문 해시·인용 ID·정책·지연·사용량)
```

**외부로 나가는 것은:** 실습의 외부 LLM 모드에서 마스킹된 질문, 질의 재작성 요청, 검색된 조항 발췌 및 답변·판정용 프롬프트. 정규식이 탐지하지 못한 개인정보가 남을 수 있다.

**나가지 않는 것은:** API 키 원문, 원본 PDF/HWP 전체, 로컬 검색 인덱스·캐시 전체, 감사 로그 파일. 내부 GPU 모드에서는 외부 LLM 호출 자체를 하지 않는다.

## 2. 질문별 답변

### Q1. 고객 개인정보가 외부 LLM에 전송되는가?

- 검색 전에 `src/finrag/agent/policy.yaml`의 `pii.patterns`로 주민등록번호·계좌번호·카드번호·휴대폰번호를 마스킹한다.
- **한계:** 이름·주소 및 비정형 개인정보는 정규식으로 탐지하지 못할 수 있다. **대응 계획:** 한국어 개인정보 인식기를 보완하고 외부 전송 직전 2차 검증과 차단 테스트를 수행한다.
- 폐쇄망의 내부 GPU 모드에서는 외부 API 전송이 없다.

### Q2. 로그에 무엇이 남는가? 보존 기간은?

| 항목 | 남는가 | 위치 |
|---|---|---|
| 질문 원문 | 아니오. `question_sha256`과 글자 수만 | `logs/audit.jsonl` |
| 인용 청크·문서 ID | 예 | 같음 |
| API 키 원문 | 아니오. SHA-256 해시 앞 12자만 | 같음 |
| 모델·프롬프트 버전 | 모델명·정책 버전은 예, **별도 프롬프트 버전은 기록 안 됨** | 같음 |
| 응답 본문 | **아니오.** 거절 여부·사유와 인용 ID만 기록 | 같음 |
| 지연·토큰 사용량 | 예 | 같음 |

**보존 기간(운영 가정):** 3개월. **파기(운영 계획):** 만료 로그 및 백업본 주기적 삭제. **접근 권한(운영 가정):** 지정된 운영·정보보호 담당자 최소 권한. 자동 파기·중앙 접근통제는 현재 실습에 구현되지 않았다. `audit.py`는 원문 대신 해시를 저장하며, 감사 로그 **24줄**을 확인했다(2026-10-13).

### Q3. AI가 잘못된 답을 하면?

- 모든 답변에 AI 생성 고지 및 원문·상담 창구 확인 안내를 포함한다.
- 근거가 없거나 부족하면 거절 또는 한계 안내를 한다. **미답변 정확도 100%(1.0), 오거절률 5.26%(0.0526)** — 6주차 40문항 `results/agentic.json` 기준.
- 계산은 결정적 함수로 처리하고 필수 값이 없으면 계산하지 않는다. 심의필 만료 근거에는 경고를 붙인다.
- 민원·분쟁·소송·해지환급금 등은 상담사 연결을 안내한다. 소규모 평가 결과이므로 실서비스 정확성을 보증하지는 않는다.

### Q4. 프롬프트 인젝션 대응은?

- 적대적 5문항(프롬프트 노출·개인정보 요구·단일 수치 단정·거래 실행·거짓 근거)을 평가한다.
- **최근 결과: [실측 통과 개수 확인 필요] / 5 통과** (`results/adversarial.json`의 `rows[].passed`; 제출 전 숫자로 변경).
- 근거 텍스트는 구분자로 분리하고, 그 안의 지시를 명령이 아닌 데이터로 다루도록 프롬프트를 구성했다. 이 시스템은 조회·안내만 하며 거래 실행 기능은 없다. 신규 공격에 대한 정기 재평가가 필요하다.

### Q5. 「인공지능기본법」상 고영향 AI에 해당하는가?

- **잠정 판단: 비해당.** 현재 기능은 약관 조회·안내에 한정되며 대출 승인·거절, 신용평가 등 개인의 권리·의무를 결정하지 않는다. 정식 서비스 출시 전 법무 검토가 필요하다.
- **근거:** 「인공지능 발전과 신뢰 기반 조성 등에 관한 기본법」 제2조 제4호 **사목**(대출 심사 등 중대한 판단·평가), 제31조 제1·2항(생성형 AI 기반 서비스 사전 고지·결과물 표시). [국가법령정보센터](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?lsJoLnkSeq=1031810747)
- **AI 고지:** 응답 `notices`에 AI 생성 사실을 표시한다. 사용자 화면의 사전 고지는 별도 확인한다.
- **재검토:** 심사·신용평가·계약 자동 결정으로 기능이 확장되거나 법령이 변경될 때.

### Q6. 망분리 요건은?

- **실습 가정: 모드 1(로컬 검색 + 외부 LLM API).** 현재 실습 구성이지 금융회사 망분리 요건을 충족했다는 뜻은 아니다.
- **폐쇄망 운영 대안: 모드 2(내부 GPU).** Qdrant·임베딩·리랭커·형태소 분석기·LLM을 내부 호스팅해 외부 API 호출을 제거한다.
- `scripts/bundle_offline.sh`와 `RESTORE.md`를 이용해 오프라인 반입·복원을 수행한다. 원본 문서는 번들에서 제외하고 반입처에서 별도 확보한다.
